# TablaPrograweb

Práctica 2 de la asignatura *Programación Web*: página que muestra una tabla
HTML maquetada con CSS.

## Contenido

- `index.html` — página con la tabla, encabezados y estilos (colores alternos
  de fila, bordes y pie de página).
- `.github/workflows/static.yml` — workflow que publica el contenido estático
  en GitHub Pages en cada push a `main`.

## Ejecutar

Sitio estático: abre `index.html` en el navegador.

## Despliegue

El workflow `Deploy static content to Pages` publica automáticamente el
repositorio en GitHub Pages al hacer push a `main`.

## Tecnologías

HTML5, CSS3, GitHub Actions / GitHub Pages.
